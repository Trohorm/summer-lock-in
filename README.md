# Lock In

Gym and diet tracker: workout splits with progressive overload, meal grading from a photo,
barcode or description, body-weight and progress photos, and friends.

**Open it:** https://web.lockin-app.online

## Add the web app to your home screen
- **iPhone / iPad (Safari):** open https://web.lockin-app.online → tap **Share** (□↑) → **Add to Home Screen** → **Add**.
- **Android (Chrome):** open the link → tap **⋮** → **Add to Home screen** (or **Install app**).

It opens full-screen like a normal app and stays signed in.

## Install on iPhone (SideStore)
1. SideStore → Sources → **Add Source** → `https://ipa.lockin-app.online`
2. Install **Lock In**. Updates appear there automatically.

## Privacy
Your data stays in your own account. Anything you share with friends is end-to-end encrypted —
only you and the friends you allow can read it.
